# (native_tts_usage.hand_off): aiohttp's writer puts an uncompressed frame on
# the transport before its first await, so a send the worker cancels was
# already handed. native_usage_selftest.py proves that property at image build;
# pin the version it was proven on so a resolver drift cannot change it.
